Built for real engineering.

Not a playground. Not a demo. A harness that runs alongside you in production codebases.

◎

Sandboxed by default

Every shell call runs under bubblewrap on Linux — network egress denied, filesystem scoped. A compromised agent can't exfiltrate or destroy.

⊘

Explicit approvals

Destructive actions are gated. You see the exact command, the reason, and choose [y]es, [n]o, or [a]lways-this-session. Nothing runs without your say.

⊞

Three operating modes

Plan for review. Build for implementation. Auto for bounded unattended work. The agent loop respects your boundaries.

⊟

Inspectable transcript

Every tool call, output, decision, and failure is rendered in the transcript. Session logs are append-only and resumable. No black boxes.

⊞

Plugin ecosystem

Skills, plugins, hooks, MCP servers, and agent manifests. Staged installs, atomic upgrades, rollback support. Extensions can't silently widen permissions.

⊡

Local-first

Your code, session history, and approvals stay on your machine. No telemetry, no cloud dependency. Works offline with local models via Ollama.

Layered by design.

Every component has an explicit boundary. Policy decides whether work may execute. Sandbox decides where. Tools decide what. No layer can bypass another.

Security isn't a feature.
It's the architecture.

tilde assumes every tool call is adversarial until proven otherwise. Policy denies by default. Sandbox restricts execution. Output is scrubbed. Extensions can't silently widen permissions.

  • ✓ Bubblewrap sandbox — network egress denied by default
  • ✓ Slopsquatting detection — hallucinated package installs flagged
  • ✓ Trust boundary enforcement — nested MCP calls approval-gated
  • ✓ Output scrubbing — secrets never leak into transcripts
  • ✓ Atomic plugin installs — staged, verified, rollback-capable
  • ✓ Fail-closed defaults — misconfiguration blocks startup, not execution
