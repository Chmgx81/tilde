Security

Security isn't a feature.
It's the architecture.

tilde assumes every tool call is adversarial until proven otherwise. Policy denies by default. Sandbox restricts execution. Output is scrubbed.

  • ✓ Bubblewrap sandbox — network egress denied by default
  • ✓ Slopsquatting detection — hallucinated package installs flagged
  • ✓ Trust boundary enforcement — nested MCP calls approval-gated
  • ✓ Output scrubbing — secrets never leak into transcripts
  • ✓ Atomic plugin installs — staged, verified, rollback-capable
  • ✓ Fail-closed defaults — misconfiguration blocks startup, not execution
# tilde's policy catches this: ✗ denied by policy: unverified package name in "pip install pyjwt-extras-fips" # Shell injection — fails closed: ✗ denied by policy: segment contains command substitution ($(...)) # Destructive rm — requires approval: ? approve: shell_command rm -rf ./build [y] approve [n] deny [a] always # Extension can't widen permissions: ✓ plugin "auth-tools" loaded tools: read_file, edit_file denied: shell_command, write_file

Architecture

Layered by design.

Every component has an explicit boundary. No layer can bypass another.

Deny by default. Every tool call passes through.

03
Tool execution
Bounded capabilities. Output scrubbed. Failures surfaced.

Everything recorded. Resumable sessions. Crash-safe.
